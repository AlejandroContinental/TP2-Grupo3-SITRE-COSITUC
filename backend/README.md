# Backend - SITRE-COSITUC

Servicio de API REST desarrollado con **Python** y **Django REST Framework**.

## Estructura Inicial Planificada

- `config/` o `sitre_api/`: Configuración general del proyecto Django (`settings.py`, `urls.py`, etc.).
- `apps/`: Módulos y aplicaciones de dominio (autenticación, recaudo, rutas, garitas, etc.).
- `requirements.txt`: Dependencias del entorno Python.
