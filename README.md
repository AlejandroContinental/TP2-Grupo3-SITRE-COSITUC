# SITRE-COSITUC

Sistema Integrado de Transporte y Recaudo - COSITUC.

## 🏗️ Arquitectura del Repositorio

El proyecto está organizado como un monorepo modular:

- **[`backend/`](./backend/)**: API REST desarrollada en **Python** con **Django REST Framework**.
- **[`frontend/`](./frontend/)**: Aplicación Web y Panel Gerencial desarrollada en **React.js** (Node.js).
- **[`mobile/`](./mobile/)**: Aplicación Móvil para usuarios y Tablet de Garita desarrollada en **Flutter**.
- **[`docs/`](./docs/)**: Documentación técnica, diagramas y especificaciones funcionales.

## 🚀 Requisitos Previos

- Python 3.10+
- Node.js 18+ / npm
- Flutter SDK 3.x
- Git
