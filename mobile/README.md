# Mobile & Tablet de Garita - SITRE-COSITUC

Aplicación multiplataforma desarrollada en **Flutter** para usuarios móviles y terminales/tablets de garita.

## Estructura Inicial Planificada

- `lib/`: Código fuente de Dart/Flutter (pantallas, widgets, modelos, controladores/blocs).
- `assets/`: Imágenes, iconos y fuentes.
- `pubspec.yaml`: Dependencias y configuración de assets del proyecto Flutter.
