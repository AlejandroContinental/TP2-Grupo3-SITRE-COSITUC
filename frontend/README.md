# Frontend Web & Panel Gerencial - SITRE-COSITUC

Aplicación web desarrollada con **React.js** (Node.js) para la gestión, administración y monitoreo del sistema.

## Estructura Inicial Planificada

- `src/`: Código fuente de la interfaz (componentes, páginas, hooks, servicios API).
- `public/`: Recursos públicos y estáticos.
- `package.json`: Dependencias y scripts de ejecución.
